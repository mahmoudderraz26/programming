خاصيات وقيم النصوص

في هذا الدرس سنتعرف على خاصيات وقيم CSS المتعلقة بالنص، والتي تمكننا من تغيير كل ما يتعلق بالنص مثل (الحجم، النوع، اللون، الاتجاه، السُمك، المسافة بين الأسطر والفقرات، المسافة قبل النص...).


خاصية تغيير لون النص وقيمها

لتغيير لون النص إلى اللون الأزرق في CSS نكتب كود مثل المثال التالي:

p {
  color: blue;
}

شرح الكود:

نبدأ بمحدد بحسب اختيارنا في هذا المثال حددنا فقرة، ثم نستخدم المعقوفات لنخبر محرر الأكواد بكل الخصائص والقيم التي سنكتبها داخله، ثم نكتب خاصية color المسؤولة عن تغيير لون النص، ثم نكتب اسم اللون blue ثم نكتب الفاصلة المنقوطة لنخبر المحرر بأننا انتهينا من كتابة الخاصية.

خاصية تغيير نوع خط النص وقيمها

لتغيير نوع خط النص إلى نوع خط معين في CSS نكتب كود مثل المثال التالي:

p {
  font-family: sans-serif;
}

شرح الكود:

خاصية font-family المسؤولة عن تغيير نوع خط النص
و Tajawal هو قيمة نوع الخط
و sans-serif هو خط احتياطي سيعتمده المتصفح في حال لم يجد الخط الأول لسبب ما.

خاصية تغيير حجم خط النص وقيمها

لتغيير حجم خط النص إلى حجم معين في CSS نكتب كود مثل المثال التالي:

p {
  font-size: 16px;
}

شرح الكود:

خاصية font- size المسؤولة عن تغيير حجم خط النص
و 16px هي قيمة حجم الخط
